# Legacy (original) scripts

These are the original exploratory scripts from the first version of the project.
They are kept for reference and reproducibility of the original results, but the
maintained, tested implementation lives in src/barbell/ and scripts/.

Run them from their own directory, e.g.:

    cd legacy/features && python build_features.py

They rely on relative paths (../../data/...) and are not part of the test suite.
